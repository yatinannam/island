# island

Windows 11 app that gives a Mac-style top "island": a black notch-shaped island springs down from the top-center edge when the cursor rests there (music first, more modules later). Owner: Yatin (yatinannam). Development now happens on his Windows 11 machine (1920x1080 at 125%, single display), so the app can be run and screenshotted locally.

## Stack and decisions

- Electron with **bun** as package manager and script runner (`bun install`, `bun run start`, `bun run dev`). Do not use npm.
- Electron 45 downloads its binary on first run, not at install.
- Keep `bun.lock` generated by Yatin's bun (1.3.x). A lockfile from a newer bun fails to parse on his machine.
- **Removed:** the ripple overlay (Yatin did not like it) and the `--acrylic` mode (rectangular window, looked bad). Do not bring them back.
- **Look:** solid black island attached to the top edge, with concave "ears" joining it to the edge, rounded bottom corners, soft shadow. Like macOS notch apps (NotchNook, boring.notch), not a floating glass pill. Real blur behind a rounded shape is not possible in Electron on Windows: CSS `backdrop-filter` in a transparent window blurs nothing, and DWM acrylic only fills a rectangle with small corners.
- **One window:** 476x188 DIP (shape 380x140 plus padding for spring overshoot, ears and shadow), transparent, always-on-top, `focusable: false`, `backgroundThrottling: false`. Hidden while closed so it never sits over fullscreen games.
- Mouse: `setIgnoreMouseEvents(true, { forward: true })` by default; the renderer sends `hover` over the shape to turn input on.
- Hover: main process polls `screen.getCursorScreenPoint()` every 16ms, uses the display under the cursor. Hot zone 240x3 DIP at top center, 150ms dwell to open. Closes 300ms after the cursor leaves the shape (+10px tolerance).
- Animation: damped spring sampled into a CSS `linear()` easing at startup (open: stiffness 240, damping 21; close: 320/38). Width/height animate; content fades and unblurs after the shape grows.
- Hotkeys: Ctrl+Alt+I pins open/closes, Ctrl+Alt+Q quits. Tray icon with Pin and Quit. Single-instance lock.
- `ISLAND_DEBUG=1` logs open/close with cursor coordinates. Do not use `--debug` as a flag: Node intercepts it.

## Testing notes

- `bun run dev` starts pinned open. Screenshot with a DPI-aware PowerShell `CopyFromScreen` of the top-center strip.
- Do not drive Yatin's mouse for hover tests while he is using the machine: his real cursor moves interfere and the results are meaningless. Ask him to test hover himself.
- Idle cost measured: about 1.3% of one core in the main process; about 430MB RAM across Electron processes.

## Roadmap

1. Media module: real now-playing from Windows SMTC (`GlobalSystemMediaTransportControlsSessionManager`). Candidate: `@coooookies/windows-smtc-monitor` (napi-rs, must run in a worker thread under Electron); fallback is a small C# helper exe over stdio. Album art, play/pause/next, scrub bar, accent color from the art.
2. Compact "live activity" peek: on track change, show a small pill for ~3s without hover.
3. Extras in order: timer, clipboard history, file shelf, voice mode (mic waveform and live transcript).
4. Ship: start with Windows, settings page, hide when a fullscreen app is active, multi-monitor polish.

## Known limits

- Overlays do not show over exclusive-fullscreen games.
- Reading other apps' notifications (UserNotificationListener) likely needs a packaged app (MSIX) with the listener capability. Unverified.
